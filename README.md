# Tensegridad — El arte del equilibrio

Web escolar en español: fundamentos, historia, fuerzas, aplicaciones, galería y fuentes. Incluye modelos 3D con giro lento y el plano de referencia convertido a metros.

Esta carpeta contiene la web lista para GitHub Pages. Conserva index.html en la raíz junto con css/, js/, assets/ y .nojekyll.

El modelo de hamaca es educativo. Las dimensiones transcriben el plano aportado; el proyecto no verifica capacidad de carga ni sustituye un cálculo estructural.
